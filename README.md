# 日程 · 最小闭环

日程安排的主干版本：只保留一份基础日历，实现 **月 / 周 / 天** 三种视图、日期导航与视图切换。日视图使用暖色规划页样式，包含时间表、便签和三态任务清单。

## 本地运行

无需安装依赖：

```bash
npm start
# http://127.0.0.1:4173
```

## 功能范围

- **月视图**：6 × 7 日期网格，非本月日期弱化，今天高亮；每天显示最多 2 项日程，超出显示 `+N 项`；点击任意日期进入对应日视图。
- **周视图**：周一到周日 7 列，07:00–21:00 时间网格；日程按起止时间定位，重叠日程自动并排；今天所在列与当前时间线高亮。
- **日视图**：左侧为 07:00–21:00 的具体时间表，日程按起止时间定位；右侧为便签纸风格便签与任务清单。任务不占用固定时间，点击状态圆点可在 `待完成 → 部分完成 → 完成` 之间切换，顶部同步显示完成进度。
- **导航**：上一个 / 下一个时间段、回到今天、月 / 周 / 日切换。
- **键盘**：`←` / `→` 翻页，`T` 回到今天，`M` / `W` / `D` 切换视图。
- **可分享状态**：`?view=month|week|day&date=YYYY-MM-DD` 可直接打开指定视图与日期。

## 暂不包含

日程 / 任务 / 便签的增删改与持久化、提醒、协作、多日历、全天日程、时区处理。示例日程、便签与任务硬编码在 `src/data.js`，任务状态仅保存在当前页面会话中，刷新后恢复初始值。

## 测试

```bash
npm test
```

覆盖日期网格、周起始、月份翻页边界、标题格式化、事件分组、重叠布局、周视图坐标计算，以及任务状态循环与完成进度统计。
