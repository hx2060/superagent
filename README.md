# 日程 · 最小闭环

日程安排的主干版本：只保留一份基础日历，实现 **月 / 周 / 天** 三种视图、日期导航与视图切换。周视图是任务 × 时间方块图；日视图采用暖色规划页结构：顶部周条、每日任务条、左侧未排期 Inbox 与便签、右侧纵向时间表。清单、周图、月视图共用同一份任务数据。

## 本地运行

无需安装依赖：

```bash
npm start
# http://127.0.0.1:4173
```

页面启动时尝试读取可选的 `local/schedule.json`（已被 `.gitignore` 忽略，不提交仓库）；文件缺失时从空白日历开始。

### 两个实例：本地 / 测试

本地与测试是**同一条代码、两个端口、两份内容**，只有 `/local/schedule.json` 不同：

| 实例 | 命令 | 内容 |
| --- | --- | --- |
| 本地 | `npm start` | `local/schedule.json`（真实本地内容，不放任何测试例子） |
| 测试 | `npm start -- --content local/examples` | `local/examples/schedule.json`（覆盖各功能的例子，用 `node scripts/gen-examples.mjs` 生成，日期相对今天） |

- `scripts/serve.mjs --content <目录>` 把 `/local/*` 请求改由该目录提供；测试实例因此不会暴露真实本地内容，`.git` 等点号路径也会被拒绝。
- 例子内容用中性占位标题，随时可改；改后刷新页面即可，不需要动代码。
- 部署机上的端口映射由反代配置（内网限制）完成：本地实例走既有常驻端口，测试实例单独一个端口。

## 功能范围

- **月视图**：6 × 7 日期网格，非本月日期弱化，今天高亮；每天显示放得下的安排、超出显示 `+N 项`；事件、定时任务、全天任务与截止任务都显示在对应日期；**跨天任务画一条长条**（1号到5号连成一个长方形），按周行裁剪、同周行最多堆叠 3 条，探出月边 / 周边的一侧为方角；只有截止日期的任务从今天画到截止日；**周行高度按内容动态延伸**——长条与 chip 放不下时整行长高、月视图内部滚动，空间富余时 6 行仍填满卡片，chip 与 `+N 项` 始终完整可见；网格上方为**逾期回顾**横幅（截止已过未删除的任务，分「逾期未完成 / 已完成」，可切换状态）；点击任意日期或长条进入对应日视图。
- **周视图**：纵轴任务、横轴 7 天；方块从任务开始日跨到截止日；只有截止日期的任务从今天画到截止日，没有截止日时占开始当天；方块内显示准确时间或截止日；任务行可直接切换三态，顶部显示本周完成进度；定时日程也各占一行；图表上方为**逾期回顾**区（截止已过未删除的任务，分「逾期未完成 / 已完成」，可切换状态，不计入本周进度）。
- **日视图**：顶部为本周日期条（含日程 / 任务色点）；左侧「清单」面板分**当日计划**（截止日 / 排期日是当天，或未完成且当天在任务区间内）与**收集区**（未排期任务，不计入日进度），日进度只统计当日计划；右侧为 07:00–21:00 的纵向时间表，日程与定时任务以彩色图标胶囊按起止时间定位，并带一行小注。
- **任务清单**：分「当日计划」与「收集区」；点击右侧圆点可在 `待完成 → 部分完成 → 完成` 之间切换，顶部同步当日计划完成进度；支持新增、改名、删除。任务可带可选的截止日期（行内显示「截止 11月8日 周日」，且不得早于任务日期）。填写开始时间与持续分钟 = 定时任务；只勾选「全天」= 当天天全天任务；两者都不填 = 放入收集区。定时 / 全天 / 截止任务都会按日期同步到日视图当日计划、周图与月视图。
- **便签**：按当天展示；支持新增、修改文本、删除；新增便签沿用黄 / 粉 / 蓝便签纸轮换。
- **每日任务**：日视图顶部的重复任务条，每天重新出现；完成状态按日期分别记录，支持三态切换与当天进度。`＋ 添加` 提供日历内手工入口；dsh 可通过 `local/schedule.json` 或 `window.schedule.dailyTasks` 下发，详见 `docs/schedule-api.md`。
- **蓄水池**：顶栏常驻入口，点击进面板；按三档学习状态（娱乐性学习 / 简单看过 / 理解学习）给出几个选项，用于空白 / 瓶颈时刻转移注意力。录入支持面板表单、`window.schedule.pool` 与本地 `pool` 键三种形式，也可从清单单向加入；详见 `docs/schedule-api.md`。
- **导航**：上一个 / 下一个时间段、回到今天、月 / 周 / 日切换。
- **键盘**：`←` / `→` 翻页，`T` 回到今天，`M` / `W` / `D` 切换视图。
- **可分享状态**：`?view=month|week|day&date=YYYY-MM-DD` 可直接打开指定视图与日期。

## 暂不包含

清单与便签的新增 / 修改 / 删除、每日任务状态和手工新增都只保存在当前页面会话；应用不会把编辑写回本地文件。具体日程内容放在 `local/schedule.json`（不提交），页面刷新后按该文件重新加载。后端接口、提醒、协作、多日历、全天日程、时区处理不在当前范围。`src/data.js` 只保留空白种子，不写真实内容。
