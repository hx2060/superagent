# 日程 · 最小闭环

日程安排的主干版本：只保留一份基础日历，实现 **月 / 周 / 天** 三种视图、日期导航与视图切换。日视图采用暖色规划页结构：顶部周条、左侧未排期 Inbox 与便签、右侧纵向时间表。

## 本地运行

无需安装依赖：

```bash
npm start
# http://127.0.0.1:4173
```

## 功能范围

- **月视图**：6 × 7 日期网格，非本月日期弱化，今天高亮；每天显示最多 2 项日程，超出显示 `+N 项`；点击任意日期进入对应日视图。
- **周视图**：周一到周日 7 列，07:00–21:00 时间网格；日程按起止时间定位，重叠日程自动并排；今天所在列与当前时间线高亮。
- **日视图**：顶部为本周日期条（含日程色点）；左侧为未排期清单与便签；右侧为 07:00–21:00 的纵向时间表，日程以彩色图标胶囊按起止时间定位，并带一行小注。
- **任务清单**：默认是未排期 Inbox；点击右侧圆点可在 `待完成 → 部分完成 → 完成` 之间切换，顶部同步完成进度；支持新增、改名、删除。填写可选的开始时间与持续分钟后，任务会绑定当天并同步到右侧时间表。
- **便签**：按当天展示；支持新增、修改文本、删除；新增便签沿用黄 / 粉 / 蓝便签纸轮换。
- **导航**：上一个 / 下一个时间段、回到今天、月 / 周 / 日切换。
- **键盘**：`←` / `→` 翻页，`T` 回到今天，`M` / `W` / `D` 切换视图。
- **可分享状态**：`?view=month|week|day&date=YYYY-MM-DD` 可直接打开指定视图与日期。

## 暂不包含

清单与便签的新增 / 修改 / 删除只保存在当前页面会话，刷新后恢复空白初始状态；日程的增删改、持久化、后端接口、提醒、协作、多日历、全天日程、时区处理不在当前范围。初始数据在 `src/data.js`，当前为空数组（首次加载不显示示例内容）。

## 目录

```

src/tasks.js         任务三态与进度统计（可单测）
src/data.js          空白种子数据（首次加载无示例内容）
src/app.js           视图渲染与交互

src/modules/         模块目录与注册约定（契约见 docs）

tests/               单元测试

```
