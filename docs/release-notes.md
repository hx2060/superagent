# 日程 · 更新说明

本文件记录每个版本**用户可见的变化**：改了什么、刷新 / 升级后要注意什么、如何重置。接口契约与纯函数细节在 `docs/interfaces.md`，机器人添加接口在 `docs/schedule-api.md`，对接方式在 `docs/integration.md`；每个版本的完整讨论、验证记录与代码在对应 GitHub PR。

0.9 之前没有独立更新说明：版本增量只以列表形式记在 `docs/interfaces.md` 第 6 节（版本与兼容）。从 0.9 起按本文件记录；追溯更早增量时看那一节与对应 PR。

## 0.9 · 本机快照（任务状态刷新后保留）

- **变化**：任务完成状态、清单 / 便签的新增 / 修改 / 删除、每日任务定义与按日状态、蓄水池条目，现在写进**浏览器本机快照**（localStorage，键 `schedule.local-state.v1`），刷新后恢复，不再「刷新就掉」。
- 写入时机：每次更改后自动合并写入；页面隐藏 / 关闭时补写一次。
- `local/schedule.json` 被机器人 / 使用者重写时：内容以文件为准，界面里新增的条目保留，任务 / 每日任务的完成状态按 id 保留。
- 存储不可用（隐私模式、配额满、快照损坏）时自动按本地内容文件 / 空白种子启动，行为与 0.8 一致。
- 快照随原点（协议 + 主机 + 端口）隔离：8080 / 8081 / 8082 三个入口各自独立，互不影响。
- **重置方式**：清除浏览器在该站点的 localStorage（或站点数据）后刷新，即回到 `local/schedule.json` 的状态。
- **注意**：同一浏览器多标签页同时编辑时后写覆盖，以最后写入的快照为准。
- 接口：`window.schedule.version` 变为 `0.9`；新增可选参数 `createDailyTaskStore(seed, { statuses })` 与方法 `listStatuses()`（向后兼容，既有调用不受影响）。
